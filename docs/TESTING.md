## 本轮自动重试

先在旧代码上运行新增测试：7 项后台测试失败，浏览器在首次 HTTP 503 后无法进入重试状态。实现后新增 8 项后台测试、9 项浏览器场景通过；原有用例全部保留。

后台覆盖可重试与不可重试 HTTP 状态、秒数与日期形式的 `Retry-After`、超过 5 分钟的等待、网络连接/响应读取中断、超时与手动取消的区分，以及无效响应和答案不重试。

浏览器使用真实本机 HTTP 服务验证：连续两次 503 后恢复且只提交一次；真实等待 25 秒超时后重试成功；429 至少等待服务方指定的 5 秒；持续失败在 3 次重试后停止且不填写/提交；401 只请求一次；重试等待中暂停、换题、刷新测验 iframe 或换课均不再请求。没有调用付费接口。

## 本轮视频停滞恢复

用户报告视频与浮层秒数停在同一位置，回到前台仍不恢复，需要手动刷新。旧代码对 `paused=false`、进度固定在 680 秒的故障注入场景持续显示播放中，新增测试在旧实现上超时失败。另覆盖 `play()` Promise 一直不返回的场景，确保不会占住检测循环。

新增 9 项浏览器用例：实际等待 15 秒后恢复播放且不修改播放位置；播放请求悬挂时仍能检测、暂停和重启；两次实际页面刷新后自动续跑且总次数封顶；刷新提示期间暂停或 iframe 变化取消刷新；有未提交答案时不刷新；提示期间进度恢复取消刷新；持续进展不会触发恢复且 30 秒后清除次数；无法访问会话存储时停止刷新。

媒体故障在隔离测试浏览器的扩展执行环境注入，不修改扩展源码。除首例真实等待 15 秒外，其他用例推动该执行环境的时钟来覆盖恢复期限，页面刷新与扩展重新注入实际执行。此前正常媒体 ended → 切章 → 测验用例继续使用真实 HTML 媒体。以上不能证明用户这次停滞的底层网络或浏览器根因；真实课程的自动恢复效果仍需用户验收。

## 核心与后台

覆盖 API 地址验证、JSON 答案、选项数量/去重、填空数量、未知题型、超长题干、只传必要字段；置信度低、缺省或格式异常均不影响有效答案，旧门槛被忽略且 API 与运行设置保留；课程脚本配置不含密钥；外部来源和独立考试页拒绝访问；课程脚本不能保存配置；暂停时不请求 AI；权限检查中取消可阻止之后的请求；API 不携带 Cookie、不跟随重定向；慢启动写入不覆盖后来的暂停；HTTP 错误不回显密钥或响应正文。

## 浏览器集成

保留 0.1.3 加入的两项真实 iframe 导航回归。更早版本在测验确认后跳到结果页时，复现用户所报“任务已暂停或页面已变化”；修复后确认完成标记、点击下一节并提交第二节测验，全程无需再次手动开始。另一场景的结果页没有完成标记，验证此时不会切章或重复提交。

保留并重跑播放、五类题目、富文本、手动/自动提交、截图、取消、页面变化和异常场景。模拟 API 默认不返回置信度，完整解答与提交流程仍通过；额外返回 20% 置信度时，正常填写并且仅提交一次。错误选项、无效 JSON 和填写回读不一致仍会停止。

新增配置升级回归：在浏览器存储中写入旧版门槛，重新打开设置后该字段不显示；API 地址、密钥及模型仍能读取，保存后仅移除旧门槛。继续覆盖上一版的 4 个场景：显式未知题型即使含“单选”关键词也不能自动填写；视频弹题关闭自动提交；错误弹题不点击继续；结果未确认的弹题不重复提交。

正常媒体用例使用真实 video 元素播放合成 1 秒 WAV，由正常 ended 事件触发任务标记。停滞场景的故障注入方式见上文；实际视频编码、平台播放器或长期挂机尚未验证。

## 生产权限冒烟

直接加载交付目录的原始 manifest，未增加任何主机权限。验证扩展和设置可用、未授权 API 时请求被阻止、没有获得 `<all_urls>` 或测试 API 授权。

42 项完整集成测试使用临时副本，为无界面环境预授权 `<all_urls>`，覆盖截图和本机 API。测试副本及测试密钥不进入发布包。真正由用户点击工具栏获取 activeTab、可选权限系统弹窗和真实 API 联通不属于这轮自动化测试的覆盖范围。
