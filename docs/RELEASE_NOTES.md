# 学习通网课 / 课伴 v0.1.3-alpha.1

首个公开预发布版本。面向 Edge 的学习通章节辅助扩展，支持视频/音频播放、完成后切章，以及使用个人 AI API 填写章节测验。

## 功能与本版修正

- 支持单选、多选、判断、填空和简答，提供自动提交开关及答案理由记录。
- 支持题目截图，需配置视觉模型并将课程页保持在前台。
- 兼容 OpenAI Chat Completions 格式，可自行填写服务地址、模型和密钥。
- 移除置信度门槛及相关暂停逻辑。
- 修复测验提交后跳转到结果页导致流程误停的问题；确认提交结果后继续下一节。
- 浮层显示实际版本，便于确认更新是否生效。

## 安装与更新

下载 `keban-edge-0.1.3-alpha.1.zip` 并解压。在 Edge 的 `edge://extensions` 开启开发者模式，选择“加载解压缩的扩展”，定位到含 `manifest.json` 的目录。源码包用户选择 `extension/`。

填写自己的 API 地址、密钥与模型，保存并测试连接，再到章节页点击“开始运行”。更新已有安装时，先在扩展卡片点击“重新加载”，再刷新课程页。详情见仓库 README。

## 验证与已知范围

- 22 项核心/后台测试、24 项隔离 Edge 集成场景通过，生产 manifest 加载与可选权限检查通过。
- 已有用户在真实课程中试用并反馈基本可用；不同学校、课程和全部题型尚未完整覆盖。
- 不支持独立考试页和复杂未识别任务；跨域 iframe、实际播放器差异和长时间运行仍需反馈。
- 答案正确率取决于模型与题目。默认启用自动填写和提交，可以先关闭自动提交进行核对。

## 数据和许可

API 密钥保存在当前浏览器本地，不同步云端。题目及可选截图仅发送到用户配置的 API，无共享题库或遥测。源码及安装包不包含开发者的真实账号、密钥、浏览器数据或第三方插件发布文件。
