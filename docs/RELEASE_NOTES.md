# 学习通网课 / 课伴 v0.1.4-alpha.2

本次增加视频停滞恢复与 AI 请求自动重试，减少播放进度不动、短暂断网、限流或服务故障导致的手动干预。

## 功能与本版修正

- 视频进度连续 15 秒不变时尝试恢复播放，间隔 15 秒重试；两次无效后刷新当前章节并续跑，连续最多刷新 2 次，持续恢复 30 秒后重置。
- 播放请求未返回也不会卡住检测循环；手动暂停、页面变化、弹题或未提交答案会取消刷新，不修改播放位置或任务点。
- 同一道题的 AI 请求遇到网络故障、25 秒超时或 HTTP 408/429/500/502/503/504 时，最多额外重试 3 次。
- 默认依次等待 3、8、15 秒；尊重服务方更长的 `Retry-After`，要求超过 5 分钟则停止。浮层显示重试进度。
- 手动暂停、换课、换题或 iframe 变化会取消后续重试。
- 密钥/权限错误、无效答案、截图错误和提交结果不明仍会停止；测验提交不会因这项功能重复执行。

## 安装与更新

下载 `keban-edge-0.1.4-alpha.2.zip` 并解压。在 Edge 的 `edge://extensions` 开启开发者模式，选择“加载解压缩的扩展”，定位到含 `manifest.json` 的目录。源码包用户选择 `extension/`。

填写自己的 API 地址、密钥与模型，保存并测试连接，再到章节页点击“开始运行”。更新已有安装时，先在扩展卡片点击“重新加载”，再刷新课程页。详情见仓库 README。

## 验证与已知范围

- 30 项核心/后台测试、42 项隔离 Edge 集成场景通过，生产 manifest 加载与可选权限检查通过；对应提交的远程 CI 结果见 GitHub Actions 及 Release 页面。
- 上一版已有用户在真实课程中试用并反馈基本可用；本版自动重试尚需实课反馈，不同学校、课程和全部题型尚未完整覆盖。
- 不支持独立考试页和复杂未识别任务；跨域 iframe、实际播放器差异和长时间运行仍需反馈。
- 答案正确率取决于模型与题目。默认启用自动填写和提交，可以先关闭自动提交进行核对。
- 自动重试可能增加 API 请求费用；电脑睡眠或 Edge 冻结标签页的问题仍需另外排查。
