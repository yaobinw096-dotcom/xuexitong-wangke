# 开源前复核

复核日期：2026-10-24；对象：0.1.3-alpha.1。

**结论：适合作为实验性开源版本发布源码，使用 GitHub Pre-release。** 本地模拟流程通过，已有用户实课试用后反馈基本可用；尚不足以承诺广泛实课兼容或无人值守成功率。

## 整理与修正

- 独立公开目录包含 extension、tests、scripts、docs、CI、问题模板、MIT 许可证和来源/隐私/贡献说明。
- 去掉本机绝对路径；测试依赖锁定，标准 npm 命令可运行，Python 标准库打包。
- 显式未知题型停止，超长题干停止；后台验证题目结构。
- 视频弹题先检查错误再继续，结果不明确即停止；关闭自动提交的分支已验证。
- 启动/暂停状态写入串行化，防止延迟写入覆盖暂停。
- 内容脚本限制到章节路径。生产权限与测试临时授权分别记录，未把测试权限带入发布版。
- 移除置信度设置和暂停条件；旧配置自动忽略该字段。低置信度和未返回置信度的有效答案均可正常填写，其他格式与提交检查继续生效。
- 修复提交后测验 iframe 跳转到结果页被误判为异常的问题；新增跨结果页继续下一节与未确认结果不重复提交的验证。

## 发布内容和来源

使用 MIT，保留公开参考项目的版权与许可文本。未打包第三方插件 bundle、反编译切片、原理分析快照、用户账户资料或浏览器 profile；开发依赖和浏览器二进制也不进入 ZIP。

公开扫描覆盖本机用户目录、常见密钥格式、运行时代码中的测试配置和原插件后台地址。ZIP 按指定公开文件范围生成，不应从本任务的上级工作目录整包上传。来源边界详见 [NOTICE](../NOTICE.md)。此项是代码与文件检查，不是全面法律审查。

## 验证结果

22 项核心/后台测试、24 项隔离 Edge 集成用例及生产 manifest 权限冒烟通过，详见 [测试记录](TESTING.md)。用户已提供实课试用反馈；开发侧测试仅操作合成课程。远程 GitHub Actions 的结果以仓库 Actions 页面为准。
